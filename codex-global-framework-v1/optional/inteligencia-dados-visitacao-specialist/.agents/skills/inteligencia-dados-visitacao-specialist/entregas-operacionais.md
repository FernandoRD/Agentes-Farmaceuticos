# Entregas operacionais

## Médico prioritário

| Campo | Conteúdo |
| --- | --- |
| Prioridade | 1 imediata, 2 desenvolvimento, 3 manutenção ou 4 monitoramento |
| Evidência | números, período e critério observados |
| Diagnóstico | interpretação separada do fato |
| Hipótese | somente se houver lacuna; indicar como confirmar |
| Ação e prazo | ação específica, responsável e data/janela |
| Indicador | medida que confirma avanço |

## Risco, churn e reativação

Classifique risco com critérios explícitos: queda de demanda/aprovação, aumento da rejeição, recência sem visita, redução de frequência, ausência de orçamento e histórico relevante. “Bom histórico + queda recente” é sinal de prioridade de reativação, não prova de perda.

## Visita e resultado

Quando houver datas, apresente a linha do tempo `visita → orçamento → aprovação → nova demanda → recorrência`. Procure padrões temporais, mas não atribua a visita como causa sem grupo comparável, janela definida ou outra evidência causal.
