# Base de Conhecimento: P&D Farmacotécnico Magistral

Este diretório contém referências compiladas, monografias de bancada e dados físico-químicos revisados para formulações magistrais:

- **Compêndios de Consulta Primária:** Farmacopeia Brasileira (6ª Edição), Formulário Nacional da Farmacopeia Brasileira, USP-NF, British Pharmacopoeia, Handbook of Pharmaceutical Excipients.
- **Bases de Dados Científicas:** PubMed / MEDLINE, SciELO, ScienceDirect, Micromedex.
- **Parâmetros Físico-Químicos Homologados:** Constantes de dissociação (pKa), curvas de pH de estabilidade e incompatibilidades descritas em literatura técnica.
