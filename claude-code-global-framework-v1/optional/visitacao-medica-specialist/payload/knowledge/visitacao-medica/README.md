# Base de Conhecimento: Visitação Médica e Evidências Clínicas

Este diretório reúne artigos científicos indexados, consensos de sociedades médicas (SBEM, SBD, ABRAN, ABP, CFM) e dados farmacológicos validados:
- **Farmacocinética Aplicada:** Perfis de absorção, curvas tempo-concentração e biodisponibilidade comparativa.
- **Monografias Clínicas:** Revisões sistemáticas e ensaios clínicos randomizados de substâncias ativas e fitoterápicos padronizados.
- **Legislação Ética de Propaganda Farmacêutica:** RDC 96/2008 da ANVISA e resoluções do CFF sobre comunicação médica.
