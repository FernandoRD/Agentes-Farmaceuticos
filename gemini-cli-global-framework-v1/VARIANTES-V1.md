# Variantes v1 para Outras Plataformas

Framework v1 especializado no setor farmacêutico para as 4 principais ferramentas de desenvolvimento com IA.

| Pacote | Plataforma | Faixas de Execução |
| --- | --- | --- |
| `gemini-cli-global-framework-v1.zip` | Gemini CLI / Antigravity | Flash / Pro |
| `claude-code-global-framework-v1.zip` | Claude Code | Haiku / Sonnet / Opus |
| `cursor-global-framework-v1.zip` | Cursor | Composer / Sonnet / Opus |
| `codex-global-framework-v1.zip` | Codex | Luna / Terra / Sol |

## Comandos de Instalação Rápida

### Linux / macOS (Bash ou Fish):
```bash
# Instalação por projeto:
./scripts/install.sh --target "/caminho/do/projeto" --apply

# Com os dois especialistas farmacêuticos:
./scripts/install.sh --target "/caminho/do/projeto" --with-all-specialists --apply

# Instalação global no $HOME:
./scripts/install.sh --global --with-all-specialists --apply
```

### Windows (PowerShell):
```powershell
.\scripts\install.ps1 -Target "C:\caminho\do\projeto" -WithAllSpecialists -Apply
```
